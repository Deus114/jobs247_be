# Recruitment

- Java 25
- Spring Boot 4
- Spring Security + JWT (OAuth2 Resource Server)
- Spring Data JPA
- MySQL
- Maven
- SpringDoc OpenAPI (Swagger)

## Môi trường

- JDK 25
- MySQL 8+
- Maven Wrapper (`mvnw`)

### Cấu hình

1. Copy `.env.example` → `.env`
2. Điền các biến môi trường trong `.env`
3. Chạy:

```bash
.\mvnw.cmd spring-boot:run
```
